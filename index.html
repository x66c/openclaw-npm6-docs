    🚀 什麼是 AI助理？

    AI助理 是一個「AI 中控台」概念的平台，透過 API 串接各種大型語言模型（LLM），讓使用者可以：

    • 不需要切換平台
    • 不需要理解複雜 API
    • 不需要寫程式

    就能直接使用 AI 能力。

    這種模式類似「AI 聚合平台」，將不同 AI 工具整合成一個工作站。
