## 小龍蝦機 vs. ChatGPT 有什麼不同？

很多人會問：👉 *「我已經在用 ChatGPT，為什麼還需要小龍蝦機？」*  
這兩者其實並不衝突，但**定位完全不同**。核心差異一看就懂：

| 比較項目 | 小龍蝦機 (私有 AI 主機) | ChatGPT (雲端服務) |
| :--- | :--- | :--- |
| **產品定位** | 自建 AI 系統（設備 + 平台） | 雲端 AI 服務 |
| **操作方式** | 透過手機直接操作你的實體主機 | 透過手機 / 電腦連線雲端 |
| **網路依賴** | ✅ 依需求（連接外部模型或 API 時需要） | ✅ 必須全程連網 |
| **AI 模型來源**| Ollama / 私有 API Key / 自選雲端模型 | 僅限 OpenAI 平台提供之模型 |
| **資料掌控度**| ✅ **完全可控**（資料留在本地，由你決定串接） | ❌ 需依賴平台隱私政策 |
| **客製化能力**| ⭐⭐⭐⭐⭐ **極高**（可深度串接工具與自動化） | ⭐⭐ 依賴官方功能，有一定限制 |
| **最佳使用模式**| 長期運作、專屬自動化流程與系統 | 即時對話、輕量級問答工具 |
